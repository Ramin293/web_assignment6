HOW IT WORKS

One click, three changes.

  1. 01

    Read the selected thumbnail’s data- attributes.

  2. 02

    Fade out the main image before updating its src and caption.

  3. 03

    Fade the new image in and mark the active thumbnail.

THE JQUERYMINI PROJECT
$(".gallery-thumb").on("click", function () {
  const image = $(this).data("image");
  $("#gallery-main-image").fadeOut(180, function () {
    $(this).attr("src", image).fadeIn(300);
  });
});
