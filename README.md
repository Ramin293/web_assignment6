# Assignment 6 — jQuery Lab

A responsive, hands-on guide to jQuery selectors, effects, DOM manipulation, and animations. The final section combines those techniques in an interactive image gallery.

## Open the project

This is a static site. Open `index.html` in a browser, or serve this folder with any local static server. jQuery 3.7.1 is loaded from the official CDN, so the interactive examples need an internet connection.

## Sections

- **Overview** — links to each part of the assignment.
- **01 Basics** — document ready, ID/class/tag selectors, `.text()`, `.html()`, and `.css()`.
- **02 Effects** — `.hide()`, `.show()`, `.toggle()`, fade methods, and slide methods.
- **03 DOM** — append/prepend/remove, changing `src` and `href`, and live form values.
- **04 Motion** — basic, sequential, and combined `.animate()` examples.
- **05 Project** — an image gallery with fading transitions and selectable thumbnails.

## Publish with GitHub Pages

The repository includes a GitHub Actions workflow that publishes the root of the `main` branch to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. After the workflow finishes, the site is available at `https://ramin293.github.io/web_assignment6/`.

## Files

- `index.html` and the five section pages contain the assignment demos.
- `assets/styles.css` contains layout and responsive styles.
- `assets/app.js` contains jQuery interactions.
- `assets/gallery-*.svg` are local illustrations used in the effects and gallery demos.
